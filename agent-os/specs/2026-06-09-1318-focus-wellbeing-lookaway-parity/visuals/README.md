# Visuals — LookAway reference screenshots

Five LookAway screenshots were provided in the shaping conversation as the parity target. They could not be written to disk from the chat session; they are described here so the spec stays self-contained. Re-attach the PNGs to this folder if you have them.

## 1. General
Sidebar groups: **Focus & Wellbeing** (Screen Breaks, Smart Pause, Wellness Reminders, Stats), **Behavior & Feedback** (Alerts/Nudges, Sounds, Keyboard Shortcuts), **Integrations** (iPhone/iPad Sync, Automation), **LookAway** (About).
Content: **Startup** (Launch at login). **Menu bar** — live preview strip (app row + waveform); two columns: *Live Status* (toggle, Display = Icon and text, Timer style = 10m) and *Screen Score* (toggle, Display, Colored rings). **Updates** — Automatically check / download, "Check for updates" button.

## 2. Screen Breaks
**General**: Show a break after = 30 minutes; Break duration = 30 seconds; rows for *Customize break screen* (chevron), *Long breaks* ("Every 4th break is a 3 mins long break"), *Office hours* (Disabled).
**Break enforcement**: 3 cards — Casual (Skip anytime), Balanced (Skip after a pause), Hardcore (No skips allowed); Snoozes per session/day (No limit); Show snoozes remaining toggle.
**More**: Double escape action (Skip the break); "Let me End break early if nearly done"; "Lock my Mac automatically when a break starts".

## 3. Smart Pause
Top: "Don't show breaks while I'm typing, dragging, or dictating".
**Automatically pause during**: Meetings or Calls (Options), Video playback (Options), Calendar Events (Grant permissions…), Deep focus apps (Options), Gaming (Options), Screen recording or sharing.
"Cooldown after smart pause ends" = 1 minute.
**Idle Tracking**: "Pause or resume when I step away" = Automatic; "Show 'Stepped Away?' dialog on returning from idle" toggle.

## 4. Wellness Reminders
Two columns: **Posture Reminder** and **Blink Reminder**, each with a preview, Enabled toggle, Show Every, Size, Position (9-point grid), Sound.
**Common settings**: Dim the screen when showing reminders; Keep reminders active during smart-pause; Prevent reminders from showing in screen recordings; Reset timers after break.

## 5. Stats
**Website usage stats**: top sites list with durations (lookaway.com 1h, x.com 30m, reddit.com 15m, youtube.com 7m). "Enable browsers where you want to track website usage": Chromium, Comet, Chrome, Safari (toggles).
